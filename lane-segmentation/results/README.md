# 결과물

`figures/kaggle-unet-bce-loss.png`와 `predictions/kaggle-unet-bce/`에는 Kaggle Lane Segmentation Challenge의 고정 validation 그룹에서 만든 baseline loss curve, best/failure 사례, 평가 JSON/CSV를 저장한다. 이 재현 결과는 포트폴리오에서 확인할 수 있도록 Git에 포함한다.

원본 이미지·mask, test submission CSV, checkpoint, 가상환경 및 Kaggle 인증정보는 Git에서 제외한다. 다른 데이터 split이나 checkpoint의 결과를 이 디렉터리에 섞지 말고, README와 실험 기록에 해당 설정을 함께 남긴다.
