# 학부 미니카 프로젝트 사진·자료 아카이브

## 증빙 상태

현재 사진, 발표자료, 코드, 부품 목록 또는 실험 기록을 전달받지 못해 자료가 없습니다. 이 폴더는 **증빙 자료를 추가할 위치**일 뿐, 과거 제작·주행·자동조향 기능을 확인하거나 입증하는 폴더가 아닙니다.

실제 원본 사진은 AI로 만들거나 다른 사람/블로그의 사진으로 대체하지 않습니다. 외부 블로그 사진은 개인 프로젝트 증거가 될 수 없습니다. 사진을 추가할 때 초상권·개인정보·게시 권한을 확인하고, 수정본은 원본과 구분하여 보관합니다.

## 사진별 기록 양식

실제 자료가 추가되면 사진마다 다음 정보를 작성합니다.

```text
파일:
촬영 시기/출처:
사진 설명:
사진에서 직접 확인되는 장비/부품:
당시 실제로 수행한 작업 (사용자 확인):
본인의 역할 (사용자 확인):
사진만으로 확인할 수 없는 기능/상태:
관련 문서/발표/코드:
```

사진에 보이는 외형만으로 내부 firmware, 자동 조향, 폐루프 차선 추종, Raspberry Pi/Arduino 종류 또는 실험 성능을 추론하지 않습니다. 주행 사진은 차량이 이동하는 모습만 보일 수 있으며, 제어 입력이나 성공 기준을 따로 입증하지 않습니다.

## 공개용 설명 상태

- 학부 자동차IT융합 과정의 LKA/차량 제어 경험은 저장소의 [`LKAS_PROJECT.md`](../../../LKAS_PROJECT.md)에 남아 있는 요약 기록을 참조합니다.
- 해당 원본과 미니카 기록의 실제 구현 범위 및 개인 역할은 자료/사용자 설명 대조 전까지 미확인입니다.
- MATLAB Dynamic Bicycle Model, PID 구현, 7개 시나리오 및 결과 데이터는 **현재 새롭게 구현한 별도 결과**이며, 과거 미니카 사진 또는 학부 원본 모델을 재현한 것이 아닙니다.
